# 260910_bag

Mobile-first digital catalog for comparing commute bags by bag weight, estimated total commute weight, and a relative perceived-load index.

- `index.html` — document structure
- `styles.css` — responsive visual design
- `app.js` — product data, thumbnail switching, comparison charts, and pinch-zoom lightbox

The perceived-load index is a comparison heuristic, not a measured physical or medical value. The current OPAQUE.CLIP bag is normalized to 100.
